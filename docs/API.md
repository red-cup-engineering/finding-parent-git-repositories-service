## Verified acceptance cases

Specification basis. Find enclosing Git repositories through their declared submodule relationships.

| Case | Check | Behavior |
| --- | --- | --- |
| ` PARENT-GIT-REFUSAL ` | source refusal | An undeclared nested repository is refused. |
| ` PARENT-GIT-QUICKSTART ` | consumer example | An installed caller reads the repository chain from its innermost mount to the outer repository. |

Runtime requirement. ` >=22 `
